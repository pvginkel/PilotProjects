# The workflow's stages

No stage of the workflow — triage, planning, a run, a close-out — is runnable from Pilot: every work
item is free-form work. Its brief is Pilot's own text — the task in a line, what to do, what to
register — which the session works out, and never opens with a stage's command. A skill of this
repo is written for a kind of work only where a brief falls short.
